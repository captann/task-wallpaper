# Task Wallpaper

Приложение для Windows, которое превращает обои рабочего стола
в доску задач с несколькими настраиваемыми стикерами.

Создавайте отдельные списки для работы, покупок, учёбы и личных дел,
размещайте их на выбранном фоне и выделяйте просроченные задачи цветом.

Приложение написано на Python с использованием PySide6.

## Как это работает

Task Wallpaper объединяет выбранный фон и стикеры в изображение,
а затем устанавливает его в качестве обоев Windows.

Стикеры являются частью изображения, а не отдельными окнами
или виджетами. Редактирование задач и отметка выполнения происходят
в приложении.

При включённом автоматическом обновлении программа отслеживает
дедлайны и обновляет обои при изменении статуса задач.

## Возможности

- Несколько независимых списков задач.
- Создание списков через кнопку `+`.
- Переименование списка двойным щелчком по вкладке.
- Изменение порядка слоёв перетаскиванием вкладок:
  слева — нижний слой, справа — верхний.
- Выбор, перемещение и изменение размера стикеров в предпросмотре.
- Добавление, редактирование, выполнение и удаление задач.
- Необязательные дедлайны с точностью до минуты.
- Настраиваемый цвет просроченных задач.
- Независимые цвета, шрифты и размеры каждого стикера.
- Возможность скрыть название и заголовки столбцов.
- Скрытие стикера без удаления его задач.
- Дублирование списков.
- Коллекция фоновых изображений.
- Шаблоны общего оформления.
- Экспорт итогового изображения в PNG.
- Работа в системном трее.
- Запуск в трее при входе в Windows через установщик.

## Интерфейс

Вкладки в верхней части окна переключают редактируемый список.
Все включённые стикеры одновременно отображаются в предпросмотре
и на итоговых обоях.

Левая панель содержит задачи и настройки выбранного стикера.
Справа находится предпросмотр рабочего стола.

### Управление

| Действие | Способ |
|---|---|
| Создать список | Кнопка `+` |
| Переименовать список | Двойной щелчок по вкладке или её контекстное меню |
| Изменить порядок наложения | Перетащить вкладку |
| Выбрать стикер | Нажать на вкладку или на стикер в предпросмотре |
| Переместить стикер | Перетащить его в предпросмотре |
| Изменить размер | Потянуть синий квадрат справа внизу |
| Редактировать задачу | Двойной щелчок по строке или кнопка «Изменить» |
| Удалить задачу | Кнопка «Удалить» или `Del` при фокусе на таблице |
| Скрыть главное окно | Закрыть окно крестиком |
| Вернуть окно | Двойной щелчок по значку в трее |
| Полностью завершить приложение | «Выйти» в меню трея |

Удаление задачи требует подтверждения.
В полях ввода и диалогах клавиша `Del` не удаляет задачу.

## Запуск из исходников

Требования:

- Windows 10 или Windows 11.
- Python 3.10 или новее.
- Возможность устанавливать зависимости через pip.

Откройте терминал в корне проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Запуск без открытия главного окна, в системном трее:

```powershell
.\.venv\Scripts\python.exe main.py --tray
```

При запуске с `--tray` автоматическое обновление обоев включается.

## Хранение данных

Настройки, задачи, шаблоны и импортированные фоны хранятся локально:

```text
%LOCALAPPDATA%\TaskWallpaper\data
```

Основной файл данных:

```text
state.json
```

Импортированные изображения хранятся в подпапке:

```text
backgrounds
```

Для резервного копирования полностью завершите приложение
и скопируйте папку `data`.

### Перенос из старой версии

Если папка данных новой версии ещё не существует, приложение
проверяет наличие данных старой версии:

```text
%LOCALAPPDATA%\TaskWallpaper\data
```

При наличии файла `state.json` данные копируются в новое хранилище.
Старый список переносится в первый стикер.

Исходные данные старой версии не изменяются.

## Шаблоны

Шаблон сохраняет:

- общий фон;
- названия и видимость стикеров;
- положение и размеры;
- порядок наложения;
- цвета и настройки шрифта;
- отображение шапки и заголовков столбцов.

Задачи в шаблон не включаются.

При загрузке шаблона существующие задачи сохраняются.
Если стикер из шаблона был удалён, он восстанавливается пустым.
Дополнительные текущие списки не удаляются.

## Проверка дедлайнов

Приложение проверяет задачи всех списков каждые 15 секунд,
а не только задачи открытой вкладки.

Чтобы изменения появлялись на рабочем столе, включите
«Автоматически обновлять обои».

При закрытии окна приложение продолжает работать в трее.
После полного выхода проверка дедлайнов прекращается.

Программа не выполняет проверки во время выключения или сна
компьютера. После следующего запуска статусы пересчитываются.

Есть возможность установки уведомлений для напоминания о дедлайне.

## Сборка приложения

Установите PyInstaller:

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
```

Соберите приложение:

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onedir --windowed --name TaskWallpaper --icon "assets\app.ico" --add-data "assets\app.ico:assets" main.py
```

Результат находится в:

```text
dist\TaskWallpaper
```

Для запуска сборки необходимо сохранить всю эту папку,
включая зависимости, а не только EXE.

### Установщик

1. Соберите приложение через PyInstaller.
2. Откройте `installer.iss` в Inno Setup Compiler.
3. Запустите компиляцию.
4. Готовый установщик появится в `installer_output`.

Установщик создаёт ярлык автозагрузки для текущего пользователя.
При следующем входе в Windows приложение запускается с `--tray`.

Перед использованием новой версии отключите автозапуск старой:
две одновременно работающие версии могут по очереди менять обои.

## Ограничения

- Приложение рассчитано на основной монитор.
- Стикеры на обоях не являются интерактивными.
- Пользовательские данные не синхронизируются между компьютерами.
- Очень длинный дедлайн в узком стикере может сокращаться.
- Если задачи не помещаются по высоте, выводится число оставшихся.
- Для обновления дедлайнов приложение должно быть запущено.
- Политики организации могут запрещать изменение обоев
  или запуск сторонних приложений.
