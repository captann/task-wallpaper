# История изменений

## 2.1.0 — 2026-11-15

### Добавлено

- Уведомления за настраиваемое время до дедлайна.
- Отдельные уведомления при наступлении срока.
- Проверка уведомлений из интерфейса.
- Сохранение отметок отправки напоминаний между запусками.
- Настраиваемая сортировка задач для каждого списка.
- Одинаковая сортировка в таблице и на обоях.
- Возможность размещать выполненные задачи внизу таблицы.
- Индикатор длительного формирования изображения.

### Оптимизация

- Отрисовка изображений перенесена в отдельный рабочий поток.
- Очередь отрисовки ограничена последним ожидающим запросом.
- Устаревшие результаты не применяются к рабочему столу.
- Во время перемещения стикеров используется уменьшенное превью.
- Добавлен ограниченный кэш подготовленного фона.
- Кодирование изображений для обоев и экспорта выполняется в фоне.
- Добавлено ожидание безопасного завершения фоновой работы при выходе.

### Примечания

- Для проверки дедлайнов приложение должно быть запущено.
- Windows может подавлять уведомления системными настройками.
- Установку обновления рекомендуется выполнять после полного выхода
  из приложения через меню системного трея.
